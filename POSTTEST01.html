Fakultas Ilmu Komputer

Profil program studi yang ada di lingkungan Fakultas Ilmu Komputer:

Daftar Program Studi

1. Sistem Informasi

Deskripsi: Mempelajari pengintegrasian solusi teknologi informasi dengan proses bisnis untuk memenuhi kebutuhan informasi organisasi.

Prospek Kerja:

  • Business Analyst
  • IT Consultant
  • Database Administrator
  • System Analyst

2. Teknik Informatika

Deskripsi: Berfokus pada penguasaan konsep komputasi, pengembangan perangkat lunak, kecerdasan buatan, dan jaringan komputer.

Prospek Kerja:

  • Software Engineer
  • Web / Mobile Developer
  • Data Scientist
  • Cyber Security Specialist

3. Desain Komunikasi Visual (DKV)

Deskripsi: Mempelajari penyampaian pesan visual secara kreatif menggunakan media digital, ilustrasi, fotografi, dan animasi.

Prospek Kerja:

  • UI/UX Designer
  • Graphic Designer
  • Animator / Motion Designer
  • Creative Director

4. Teknik Sipil

Deskripsi: Berfokus pada perancangan, pembangunan, dan pemeliharaan infrastruktur fisik serta lingkungan dengan dukungan teknologi komputasi (BIM/CAD).

Prospek Kerja:

  • Structural Engineer
  • Project Manager Konstruksi
  • BIM Specialist
  • Konsultan Infrastruktur
